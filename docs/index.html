Everything you expect

Full bash compatibility with modern developer experience.

⚡

14ms Startup

Tested on an Intel Celeron N3060. On modern hardware, it's under 10ms.

🎨

8 Built-in Themes

Catppuccin, Tokyo Night, Gruvbox, Nord, Solarized, Dracula, OneDark, and more.

📝

Syntax Highlighting

Real-time colorization of commands, strings, variables, and operators as you type.

💡

Autosuggestion

History-based inline suggestions. Accept with →, continue typing to dismiss.

📦

2.0 MB Binary

Single static binary with LTO, stripped symbols, and panic=abort. No runtime deps.

🔌

Plugin System

TOML-based .aster files with dependency resolution, alias injection, and script sourcing.

🔀

Full Expansions

$(cmd), $((expr)), ${var:-default}, {a,b}, {1..5}, ~, **, $VARIABLE.

📋

Tab Completion

Commands, paths, dirs, env vars, tilde. Smart completion for cd, source, export.

🔒

Rust Safety

Workspace-wide unsafe_code = "deny" with strict Clippy lints. Zero unsafe code.
